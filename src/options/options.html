Bro Chat 網址設定

請提供已啟用翻譯 Skill 的 Gemini 對話完整網址（例如：https://gemini.google.com/app/4d870f290f0c5975）。 Talk To Bro 會在背景將內容送至 Bro Chat 並取回完整回答。

Talk Log 統計

僅統計已完成的成功、送出失敗與讀取失敗次數，不記錄任何對話內容。

全域快捷鍵

預設開啟 Talk To Bro 的全域快捷鍵為：

Alt + Shift + B

若需自訂快捷鍵，請至 Chrome 的 chrome://extensions/shortcuts 設定頁進行修改。
