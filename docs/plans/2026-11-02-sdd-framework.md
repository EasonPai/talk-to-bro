# SDD 導航框架建立計畫

日期：2026-11-02

## 核准與範圍

董事會已核准對話預覽並指示 go，且確認目標為目前獨立 talk-to-bro repository。建立最小 SDD 入口，不搬移、不拆分、不覆寫既有規格。

## 步驟

1. 新增 [SDD Index](../sdd/README.md)：文件責任、摘要、關鍵詞、必要共讀與局部讀取規則。
2. 新增 [Overview](../sdd/overview.md)：系統邊界及元件責任摘要，不宣稱實作完成。
3. 在 [專案 README](../../README.md) 加入入口。
4. 依專案要求同步遞增 package、lockfile 與 manifest patch 版本，保留原有未提交修改。
5. 驗證新增文件的本地連結、版本一致性與 diff whitespace。文件變更不涉及程式行為，不執行發布或合併。

## 權威與安全

沿用既有 PRD、Tech Spec 與主題規格；新入口不自動取代它們。Notion 與本地文件權威關係、主題規格取代範圍若未確認則標記待確認。未啟用 Graphify 索引時不為此初始化。團隊 whoami 未能識別本終端；本次依董事會直接核准執行文件示範，不冒充團隊角色或修改派工狀態。

## 驗收

- 新入口可導航至既有規格，沒有重複完整技術內容。
- 包含無 Graphify、單檔分段讀取與衝突處理規則。
- 所有新增本地連結可解析；版本同步；沒有改動既有規格內容。
