# Talk To Bro — SDD Index

日期：2026-11-02 · 狀態：初始導航框架

## 核心摘要

本 SDD 採「精簡索引＋主題文件」：先讀本入口，再讀本次需要更新的規格章節與必要相依內容。Single Source of Truth 不等於單一大檔；每個議題應只有一個權威存放位置。

目前沿用既有 PRD、Tech Spec 與主題規格，不搬移或重複完整內容。本入口不是新的需求核准，也不代表所有設計已實作或驗證。

## 產品目的

Chrome MV3 擴充套件，讓閱讀中的使用者透過快捷鍵與查詢介面輸入英文單字／片語，由既有 Gemini Bro Chat 解答，再於介面讀取結果；自動化失敗時提供 Handoff 退路。

## 更新 SOP

1. 每次使用 KT 時確認本次選擇「記錄到 SDD」或「照原本知識庫流程」，不沿用上次選擇。
2. 選擇 SDD 後，先用本索引確認主題目的地及必要共讀文件。
3. 若存在可用 Graphify 索引，依專案規範先查詢相關概念與跨文件關係，再核對目前原文。目前未發現本 repository 的 Graphify 索引，不為單次整理初始化。
4. 對既有大型單檔先搜尋目錄／標題，再分段讀取目標章節與相關約束。行號只作本次定位，不作穩定識別碼。
5. 把對話回答整理成正式內容寫入唯一目的地，保留圖解、前提與決策脈絡；不要貼聊天逐字稿。
6. 若與已核准規格矛盾、權威來源不明或影響範圍不確定，先提出差異請董事會確認。提案／待確認內容不可改寫成已採納設計。
7. 只有新增主題、收錄範圍或必要相依關係改變時才更新索引；不把詳細規格複製回索引。
8. 新主題確實需要時才新增小文件；既有單檔不強制拆分。搬移與拆分另行規劃核准。
9. 回報實際修改文件與摘要；有既有圖索引時依專案維護規範更新，不宣稱過期圖已同步。
