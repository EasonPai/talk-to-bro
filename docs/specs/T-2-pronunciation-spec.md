# T-2 規格：回覆英文單字點擊發音

來源：[已核准計畫](../plans/2026-11-04-T-2-word-pronunciation-plan.md)。驗收條件 M1–M8、S1 以計畫為準。

## 使用者結果

閱讀 Bro 回覆時，點擊英文單字即播放英文發音。Popup 與側邊欄行為一致。

## 已確認行為

- 一般文字、標題、清單、表格內的英文單字可點；連結、程式碼、按鈕不可觸發。
- 平常外觀不變，滑鼠移入單字才顯示淡底色或細底線。
- 拖曳選字、已有文字選取時的點擊不發音；複製與閱讀展開不變。
- 詞內撇號與連字號保留（`don't`、`mother-in-law`）；不朗讀標點、純數字或含數字識別字。
- 固定 `en-US`、正常語速；最新點擊取消前一次播放，不排隊。
- 無法播放時顯示簡短提示；不接雲端語音、不新增權限。

## 技術邊界

- 瀏覽器原生 Web Speech API；在清理後的 DOM 上以 DOM API 包裝單字，不拼接 HTML。
- 在共用回答容器委派事件，重複渲染不累積 listener。
- 語音狀態只存在各頁面文件，不寫 SW 或 storage。
- 先以真實 CfT 驗證擴充套件頁面可發聲（M1）；無法驗證就 `work block`，不自行換方案、不冒充通過。

## 不做

口音或語速設定、逐詞鍵盤操作、雲端語音、跨文件播放仲裁、離頁主動停止。
